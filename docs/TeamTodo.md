  - 2~6인 지원 범위 (시연은 3인 이상)

### 수치 확정 (ConfigTable 시트에 입력)
시트 `ConfigKey` 열에 아래 키 이름 그대로 넣으면 게임에 반영된다 (ValueType: Float 또는 Int). 시트에 없으면 오른쪽 기본값으로 돈다.

| ConfigKey | 뜻 | 기본값 |
| --- | --- | --- |
| `Round.Count` (Int) | 회차 제한 | 5 |
| `Time.Record` | 자동차 녹화 시간(초) | 10 |
| `Time.Task` | 역할별 작업 시간(초) | 15 |
| `Time.Reveal` | 현황 공개 시간(초) | 15 |
| `Time.PlayExtra` | 입력이 끝난 뒤 재생을 더 기다리는 최대 시간(초) | 8 |
| `Road.Ink` | 잉크량(길 총 길이, 유닛) | 12 |
| `Road.Friction` | 길 마찰 | 0.8 |
| `Trap.Count` (Int) | 함정 개수 | 2 |
| `Trap.ForceX` / `Trap.ForceY` | 함정이 뒤로 / 위로 튕기는 힘 | 4 / 6 |
| `Car.Mass` / `Car.WheelMass` | 차체 / 바퀴 질량 | 1 / 0.3 |
| `Car.MotorSpeed` | 바퀴 회전 속도(도/초) | 500 |
| `Car.MotorTorque` | 바퀴 힘 | 20 |
| `Car.TiltTorque` | 기울기 힘 | 3 |
| `Weight.Light` / `Weight.Heavy` | 가벼움 / 무거움 질량 배율 | 0.6 / 1.8 |
| `Gravity.Low` / `Gravity.High` | 낮음 / 높음 중력 배율 | 0.5 / 1.6 |
| `Weather.Wind` | 맞바람/뒷바람 힘 | 4 |
| `Weather.RainFriction` | 비 올 때 바퀴 마찰 | 0.3 |
| `Surface.NormalFriction` / `Surface.MudFriction` / `Surface.IceFriction` | 재질별 마찰 | 0.8 / 0.8 / 0.05 |
| `Surface.MudDrag` | 진흙 위 감속 | 3 |

맵 길이(3화면)와 구간 수(화면당 3개)는 코드 상수다 (`Track.cs`).

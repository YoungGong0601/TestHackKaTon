# 완성도 점검표

> 원본: https://www.notion.so/40fa56ac5c28815ca7d7ee3a2fd05120

🟡 일정과 빼는 순서는 팀과 맞춘다.

> #### 불편이 의도로 보이게

- [ ] 터치 실패에 손가락이 빗나가는 애니메이션과 소리를 넣는다
- [ ] 문이 안 열릴 때 덜컹거리는 소리와 대사를 넣는다
- [ ] 지폐가 튕겨 나올 때 소리와 "카드 전용" 안내를 같이 보여 준다
- [ ] 1회차를 가장 매끄럽게 만든다
- [ ] 아무 반응이 없는 입력을 남기지 않는다. 안 되는 이유를 소리와 문구로 바로 알려 준다

> #### 흐름

- [ ] 자정까지 1회차부터 엔딩까지 잇는다 (회색 화면이어도 된다)
- [ ] 2026-11-06에 기능을 동결하고, 그 뒤로는 버그만 고친다
- [ ] 시간이 모자라면 음성 안내, 아이콘만, 좁은 버튼 순으로 뺀다

> #### 공통 틀

- [ ] 버튼 눌림 효과와 효과음을 넣는다
- [ ] 회차 전환 연출을 넣는다
- [ ] 키오스크 화면의 스타일을 회차마다 맞춘다

> #### 테스트

- [ ] 처음 보는 사람에게 말없이 플레이하게 하고 멈춘 곳을 적는다
- [ ] 모든 회차에서 쪽지로 무엇을 살지 알려 준다

> #### 심사 준비

- [ ] 제출할 빌드 파일로 처음부터 끝까지 돌려 본다
- [ ] 처음으로 돌아가는 키를 넣는다
- [ ] 헤드폰이나 스피커를 준비한다
- [ ] 임시 문구와 오타를 없앤다

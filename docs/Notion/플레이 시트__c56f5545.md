# 플레이 시트

> 원본: https://www.notion.so/40fa56ac5c2881879542ece2c56f5545

시작부터 엔딩까지 플레이어가 겪는 순서다. 2D와 3D 개발에 같이 쓴다. 표시 없는 내용은 기획 문서에서 가져왔고, 🔴는 초안이라 고칠 수 있다. 구현 규칙은 [페이지](https://www.notion.so/40fa56ac5c28801390d7fddd7e3f2fc2)의 「AI 작업 안내」를, 아직 정해지지 않은 항목은 [페이지](https://www.notion.so/40fa56ac5c28810a91e8e1d2e3003954)를 따른다.

> #### 공통 규칙

- 🔴 조작은 클릭이다. 3D는 1인칭으로 걷고 2D는 좌우로 움직인다. 어느 쪽이든 캐릭터는 손만 보인다.
- 시대와 플레이어는 같고, 회차마다 나이가 다른 캐릭터를 다룬다. 나이 숫자는 보여 주지 않는다.
- 성별은 정하지 않고 호칭을 쓰지 않는다.
- 회차 사이에는 눈이 감겼다가 뜨면 손이 더 나이 든 캐릭터의 손으로 바뀐다.
- 🔴 1~3회차는 시작할 때 목표를 한 줄로 보여 준다. 4회차에는 목표 문구가 없고 쪽지가 대신한다.
- 막혀도 자동으로 넘어가지 않는다. 4-10a만 예외다. 실패해도 넘어갈 수 있는 곳은 🔴 3회차 영화관과 4회차 버거집, 버스뿐이다.
- 모든 회차에 시연자용 디버그 모드와 처음으로 돌아가는 키를 넣는다. 심사위원이 실수로 누르지 않는 키 조합으로 한다.
- 아무 반응이 없는 입력을 남기지 않는다. 안 되는 이유를 소리와 문구로 바로 알려 준다.
- 회차가 갈수록 안내음과 주변 소리가 먹먹해진다. 뒷사람의 한숨과 재촉은 먹먹해지지 않고 또렷하게 들린다.
- 눈치 게이지: 화면에 보인다. 오래 걸릴수록 줄이 길어지고 한숨과 재촉이 들리며 게이지가 찬다. 넘어가는 버튼은 🔴 3회차와 4회차 버거집에만 생긴다.
- 고개 돌리기: 고개를 돌려 뒷줄과 알바생을 볼 수 있다. 돌린 동안 키오스크는 안 보이고 시간은 흐른다.
- 같은 자리, 다른 대접: 나이가 많은 캐릭터일수록 같은 상황에서 사람들이 외면하고 재촉한다.
- 같은 글씨, 다른 눈: 1회차에 또렷하게 붙어 있던 글씨가 4회차에는 같은 자리에서 돋보기 없이 읽히지 않는다. 키오스크의 "카드 전용" 스티커, 벽의 "누구나 쉽고 빠르게!" 포스터, 정류장과 버스 단말기의 "현금 없는 버스 운행 안내"가 해당한다.
- 줄과 알바생 장면을 보여 주는 방법은 개발자 재량이다.
- 실제 서비스 이름은 개발자가 임의로 바꾼다.
- 표의 순서 열에 「언제든」이 붙은 행은 순서와 상관없이 조건이 되면 일어난다. 「실패」와 「선택지」 행도 순서에 들어가지 않는다.

> #### 1회차 버스와 버거집 (20대)

🔴 목표: 112번 버스를 타고 버거집에 가세요. 디버프 없음, 돋보기 필요 없음, 결제는 카드, 눈치 게이지는 거의 차지 않는다.

| 순서 | 플레이어가 하는 것 | 일어나는 일 | 대사와 문구 | 연출과 소리 |
|---|---|---|---|---|
| 1-1 | 정류장에서 안내를 본다 | 몇 번 버스를 타라는 안내가 나온다. 전광판 글씨가 잘 보인다 | 🔴 "112번 버스를 타세요." | 구석의 "현금 없는 버스 운행 안내"가 또렷하게 보인다. 4-13과 같은 자리다 |
| 1-2 | NPC에게 묻는다 (안 물어도 된다) | 친절하게 알려 준다 | 🔴 행인: "112번 타시면 돼요. 곧 와요." | 🔴 4회차에 같은 행인이 외면한다 |
| 1-3 | 버스 계단을 오른다 | 🔴 쉬운 마싱으로 금방 오른다. 카드를 찍고 탄다 |  | 🔴 카드 찍는 소리. 단말기의 "현금 없는 버스 운행 안내"가 또렷하게 보인다. 4-21과 같은 안내문이다 |
| 1-4 | 버거집 앞에서 문을 당긴다 | 🔴 "당기세요"가 잘 보여 한 번에 열린다 |  | 🔴 4회차와 비교되는 장면이다 |
| 1-5 | 줄에서 기다린다. 고개를 돌려 볼 수 있다 | 앞에서 어르신이 키오스크에서 헤맨다 | 🔴 어르신: "왜 안 되지?" | 플레이어 캐릭터의 한숨 소리. 어르신의 소매와 반지, 손목시계가 보이게 그린다 |
| 1-6 | 입력 없음 | 어르신이 카드 넣는 곳에 지폐를 넣는다. 3번 튕겨 나오면 플레이어 캐릭터가 한마디 하고, 어르신은 슬픈 얼굴로 가게를 나간다 | 플레이어 캐릭터: "그거 지폐 안 받아요." 어르신: "그려? 어쩔 수 없구만..." | 이 장면을 강조한다. 4회차에서 알아볼 복선이다. 나가는 뒷모습을 보여 주고, 엔딩에서 같은 구도로 다시 쓴다 |
| 1-7 | 키오스크로 주문한다 | 매우 쉽다. 알바생이 먼저 인사한다 | 🔴 알바생: "어서 오세요!" | 🔴 버튼음. 키오스크의 "카드 전용" 스티커와 벽의 "누구나 쉽고 빠르게!" 포스터가 또렷하게 보인다 |
| 1-8 | 불고기 버거 세트를 고르고 카드로 결제한다 | 바로 승인된다 |  | 🔴 승인음 |
| 1-10 | 번호가 불리면 버거를 받는다 | 픽업도 매우 쉽다 | 🔴 "274번 고객님, 주문하신 메뉴 나왔습니다." |  |
| 1-11 | 🔴 다 먹고 가게를 나온다 | 2회차로 넘어간다 |  | 회차 전환 |
| 언제든 1-9 | 알바생에게 묻는다 (안 물어도 된다) | 매우 친절하게 안내해 준다 | 🔴 "여기 누르시면 돼요. 제가 도와드릴게요." |  |

> #### 4회차 버거집 (80대)

목표 문구를 화면에 보여 주지 않는다. 플레이어는 4-0의 쪽지를 보고 무엇을 할지 스스로 정한다. 이 캐릭터는 1회차의 그 어르신이다. 같은 장면을 반대쪽에서 다시 플레이한다. 결제 수단은 현금뿐이다. 🔴 걸음이 느리다. 이 회차에서는 아무도 도와주지 않는다. 도움을 받는 분기를 만들지 않는다.

| 순서 | 플레이어가 하는 것 | 일어나는 일 | 대사와 문구 | 연출과 소리 |
|---|---|---|---|---|
| 4-0 | 🔴 지갑 속 쪽지를 돋보기로 본다 | 회차가 시작되면 손에 지갑이 들려 있고 지폐 옆에 손글씨 쪽지가 있다. 🔴 글씨가 흐려 돋보기로 봐야 읽히고, 읽어야 걷기 시작한다. 누가 썼는지는 밝히지 않는다 | 🔴 쪽지: "불고기 버거 세트" "112번 버스" 🔴 돋보기 없이 볼 때 캐릭터: "뭐라고 썼더라." | 미션 UI를 대신한다 |
| 4-1 | 버거집 문을 민다 | "당기세요"를 못 보고 밀어서 문이 안 열린다 | 🔴 "어? 왜 안 열려." | 🔴 문이 덜컹거리는 소리로 버그가 아님을 보여 준다 |
| 4-2 | 돋보기로 문을 본다 | "당기세요"가 읽힌다. 당겨서 들어간다 | 🔴 "아, 당기는 거구먼." |  |
| 4-3 | 키오스크 앞에 선다 | 뒤에서 1회차 캐릭터가 기다린다. 손에 1회차 어르신의 소매와 반지, 손목시계가 보인다 |  | 1회차에 또렷했던 "카드 전용" 스티커와 "누구나 쉽고 빠르게!" 포스터가 같은 자리에 있지만 돋보기 없이는 읽히지 않는다 |
| 4-4 | 돋보기로 화면을 본다 | 글씨가 안 보이고 돋보기를 든 손이 떨린다. 돋보기로 봐도 초점이 가끔 흐려진다 |  | 🔴 서서히 흐려졌다가 돌아와 버그로 보이지 않게 한다 |
| 4-5 | 쪽지에 적힌 불고기 버거를 찾는다 | UI가 매우 작아서 클릭하기 힘들다. 메뉴 버튼은 숨겨져 있다. 🔴 옆 버튼이 눌리고 가끔 터치가 안 된다. 🔴 다른 메뉴를 담아도 막지 않는다 | 🔴 "이건 또 뭐야." |  |
| 4-8 | 다음을 누른다 | 🔴 코드 등록, 앱 가입, 포인트 적립 팝업이 뜨고 사이에 로봇 인증이 나온다. 마지막 x를 누르면 처음으로 돌아간다 | 🔴 "처음 화면으로 돌아갑니다." | 🔴 팝업음 |
| 4-10 | 결제 창까지 간다. 지폐를 집어 카드 넣는 곳에 넣는다 | 현금을 받지 않아 결제할 수 없다. 지폐는 넣을 때마다 튕겨 나온다 | 🔴 "카드 전용" 안내, 캐릭터: "돈을 어디다 넣으라는 거야." | 버그로 보이지 않게 튕길 때마다 소리와 "카드 전용" 안내 깜빡임을 같이 보여 준다. 지폐를 집을 때 지갑 속 쪽지가 같이 보인다 |

| 4-10b | 문까지 걸어 나간다 | 키오스크 앞에 서 있던 사람들이 나를 계속 바라본다 |  | 🔴 사람들의 고개가 나를 따라 돌아간다. 걸음이 느려 시선을 오래 받는다 |
| 언제든 4-0a | 🔴 지갑을 열어 쪽지를 다시 본다 | 🔴 버거집과 버스 어디서든 볼 수 있다. 보는 동안 시간은 흐른다 |  |  |

> #### 4회차 버스 (80대)

버거집을 나와 정류장으로 간다. 돋보기 초점은 여기서도 가끔 흐려진다. 버스 3대를 보내는 동안 정류장이 저문다. 🔴 첫 번째 버스는 낮, 두 번째 버스는 노을, 세 번째 버스가 떠날 때는 해 질 녘이고 가로등이 켜진다. 버스가 떠날 때마다 입력 없이 캐릭터가 손목시계를 보며 시간이 지났음을 강조한다. 숫자 없는 바늘 시계라 돋보기 없이도 바늘이 보인다.

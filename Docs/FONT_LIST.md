# 서울알림체 대상 목록

출처: 서울알림체 서울특별시
폰트 파일과 TMP 폰트 에셋은 프로젝트에 넣지 않는다. 프로젝트 밖에서 PIL로 PNG를 만들어 PNG만 넣는다. 블러용 그림은 따로 굽지 않는다.
제목은 Bold, ExtraBold, Heavy, 작은 글은 Medium.

## 교체함
| 대상 | PNG | 재질 |
|---|---|---|
| 노선 안내판(R1_Stop, R4_Stop) | Graybox/Materials/RouteMap.png | M_RouteMap |
| 현금 없는 버스 안내문(R1_Stop, R4_Stop) | Graybox/Materials/Sign_NoticeCash.png | M_Sign_NoticeCash |
| 당기세요 스티커(PH_Door_Glass) | Graybox/Materials/Sign_Pull.png | M_Sign_Pull |
| 수령 컵 라벨 | Graybox/Materials/T_Cup_Cola.png, T_Cup_Cider.png | M_Cup_Cola, M_Cup_Cider |

## 교체 안 함
| 대상 | 이유 |
|---|---|
| PH_BIS 전광판 | 전광판 글자는 도트 표시 느낌의 TMP, 시간 표시가 바뀔 수 있어 목록만 적음 |
| R2_Cafe 숲길 커피(PH_CafeFront/Sign) | 미처리, 후속 대상 |
| 시작 화면, 결과 화면 고정 문구 | 미처리, 후속 대상 |
| Sticker_CardOnly, Plate SCAN, PRINT, CARD, Receipt_View | 키오스크 쪽 담당 |
| Hand_Note 쪽지, 자막, 키오스크 UI | 지시 제외 |

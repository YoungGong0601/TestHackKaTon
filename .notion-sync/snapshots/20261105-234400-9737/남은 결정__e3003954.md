# 남은 결정

> 원본: https://www.notion.so/40fa56ac5c28810a91e8e1d2e3003954

> #### 정해야 할 것

- [ ] 심사위원이 테이블에 머무는 시간을 운영진에게 확인
- [ ] 2D와 3D 중 제출할 버전을 언제 정할지
- [ ] 플레이 시트의 🔴 항목 검토
- [ ] 키오스크 메뉴, 팝업 문구
- [ ] 아트 톤 기준
- [ ] 엔딩 통계 문구를 보고서 원문과 대조

> #### 구현 전에 물어볼 것

AI는 아래 두 표의 항목을 임의로 정하지 말고 사용자에게 묻는다.

##### 먼저 정할 것

한 줄이 게임 전체의 입력이나 화면에 걸린 항목 하나다. 구현을 시작하기 전에 묻는다.

| 항목 | 정해지지 않은 것 |
|---|---|
| 3D 입력 | 걷기와 시점을 어떻게 조작하는지, 키오스크 앞에서 포인터로 바뀌는지, 고개 돌리기가 자유 시점인지 전환인지 |
| 2D 화면 | 손만 보이는 캐릭터를 어떻게 그리는지, 키오스크 앞에 서기와 고개 돌리기가 2D에서 무엇인지 |
| 돋보기 | 언제 얻고 어떻게 켜고 끄는지, 1회차와 2회차에도 있는지, 문과 전광판 같은 바깥 글씨에도 같은 방식인지, 렌즈 안의 클릭을 어떻게 판정하는지 |
| 결제 입력 | 클릭만으로 지갑에서 카드 꺼내기, 카드 찍기, 지폐 넣기를 어떻게 하는지. 지폐를 넣는 입력 한 번이 3번 튕김의 기준이다 |
| 마싱 | "아주 어렵다"가 횟수 말고 무엇인지, 멈추면 내려가는지 |
| 눈치 게이지 | 어떤 모양으로 보이는지, 넘어가는 버튼이 어디에 뜨는지(고개를 돌린 동안에는 키오스크가 안 보인다), 4회차 대사의 낮음·중간·높음 경계 |
| 대사 | 자막인지 음성인지 |
| 디버그 | 넘기는 단위(회차, 4회차 버거집과 버스, 엔딩)와 키 조합 |

##### 장면별로 물어볼 것

한 줄이 아직 정해지지 않은 장면 하나다. 그 장면을 만들기 전에 묻는다.

| 장면 | 정해지지 않은 것 |
|---|---|
| 1-2, 4-14 | 1회차 정류장과 4회차 정류장이 같은 곳인지, 같은 112번의 방향을 어떻게 볼지 |
| 1-3, 1-4, 2-1, 4-10b 뒤 | 장소 사이를 직접 걷는지 컷으로 넘기는지 |
| 1-5, 1-6 | 줄에서 앞으로 가려 할 때 어떻게 막는지, 입력이 없는 동안 카메라를 고정할지. 뒤를 보고 있으면 복선 장면을 놓친다 |
| 1-6, 4-10a, 4회차 선택지 | 손만 보이는 시점에서 슬픈 얼굴을 어떻게 보여 줄지. 1회차 어르신의 얼굴을 보여 주면 성별을 정하지 않는다는 규칙과 부딪힌다 |
| 1-10, 1-11, 2-7 | 내 호출 번호를 어디서 알려 주는지, 놓침 판정과 받는 동작, 다 먹는 모습을 보여 주는지 |
| 3-2 | 3회차에서 돋보기 없이는 어떤 UI가 안 보이는지 |
| 3-8 | 문자로 온 번호를 어디서 보는지(휴대폰 화면은 게임에 없다), 틀리거나 30초를 넘기면 어떻게 되는지 |
| 3회차 실패, 4회차 실패 | "조금만요"를 고른 뒤 버튼이 언제 다시 생기는지 |
| 4-0, 언제든 4-0a | 지갑과 쪽지를 여는 입력, 2D에서 쪽지를 어떻게 보여 줄지 |
| 4-1, 4-2 | 클릭만으로 문 밀기와 당기기를 어떻게 나누는지 |
| 언제든 4-5a | 큰 글씨 모드의 연출 방법. 레퍼런스는 개발자에게 있다 |
| 4-8 | 팝업을 지나 결제 창으로 넘어가는 방법 |
| 언제든 4-9 | 남은 시간을 어디에 어떤 모양으로 표시하는지, 시간 초과 40초를 언제부터 세는지, 처음 화면으로 돌아갈 때 게이지, 줄, 큰 글씨 모드, 지폐 튕김 횟수가 초기화되는지 |
| 4-10b | 1인칭에서 등 뒤에 있는 사람들의 시선을 어떻게 보여 줄지, 플레이어가 걷지 않고 멈추면 어떻게 되는지 |
| 4회차 버스 | 표시 없는 행동(4-11, 4-12, 4-14)이 필수인지 |
| 4-15~4-19 | 번호판을 돋보기로 제대로 읽으면 실제 번호가 보이는지, 타지 않으면 어떻게 되는지, 기사에게 묻는 것이 필수인지, 다음 버스가 언제 오는지 |
| E-1, E-2 | 뒷모습 컷에 몸 모델이 필요한지(성별 규칙), 제목 뒤에 처음으로 돌아가는지 |
| 대화 표 | "어르신, 그거 아니에요."가 호칭을 쓰지 않는다는 규칙과 부딪힌다 |
| 개요 결제 수단 | 삼성페이가 게임에 나오는지. 지금 뒷사람은 카드로 결제한다 |

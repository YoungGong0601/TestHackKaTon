# 프로토타입 설명

## 파일
- index.html: 키오스크 화면만 단독으로 눌러 보는 2D 페이지. 3D 없음. 1080x1920 화면 코드는 3D 게임과 같은 원본이다. 더블클릭으로 열린다.
- first.html: 첫 프로토타입 "다음 차례". 한 컷씩 클릭 또는 Space로 넘기는 장면형 시안.
- 3d.html: 3D 전체 게임 "불고기 세트 하나"(약 28MB). 현관에서 시작해 정류장, 매장, 키오스크 주문까지 1인칭으로 진행한다. 기획 원문은 Prototype 폴더의 3d prompt.md.
- images/: 음식 그림 PNG(투명 배경, 이름은 메뉴 id).

## index.html 조작
- 화면을 마우스로 클릭하면 터치다. 눌리는 곳에 원이 퍼진다.
- 오른쪽 "본체" 버튼이 3D 몸체 조작을 대신한다. 카드 결제 순서는 덮개 열기, 카드 넣기 / IC 틈(첫 번째는 방향 오류로 튕김), 한 번 더 IC 틈, 결제 후 카드 빼기, 영수증이 나오면 영수증 떼기.
- 바코드 틈, 영수증 틈은 틀린 틈 시험용이다.
- 뜻 풀이: 3D에서 돋보기로만 보이던 괄호 풀이를 화면에 겹쳐 보인다.
- 시간 제한: 켜면 90초 무입력 시 처음으로 돌아간다. 기본은 꺼짐.
- 처음부터 다시: 전체 초기화.
- 눈치 게이지, 번짐, 소리는 없다. 음성 대사는 오른쪽 아래 글자로만 나온다.

## images
- 메뉴 id.png: 단품 그림(420x320)
- 메뉴 id_combo.png, id_large.png: 버거의 세트, 라지세트(520x340)
- 메뉴 id_big.png: 버거 큰 그림(1000x860)
- bag.png, tray.png: 포장 봉투, 쟁반
